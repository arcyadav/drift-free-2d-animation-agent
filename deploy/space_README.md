# Drift-Free 2D Character Animation Agent (UMC301 Project 3)

Type what the character should do; a planner turns it into a plan and a rig-based animator renders
the clip on CPU. No video generation model: the character never changes between frames or clips.

Code: https://github.com/arcyadav/drift-free-2d-animation-agent
